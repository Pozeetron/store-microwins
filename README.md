# store-microwins

Google Play assets for **Micro-Wins** (Angel Mobi).

## Privacy Policy (GitHub Pages)

After enabling Pages (`Settings → Pages → Deploy from branch → main / root`), the policy URL will be:

https://pozeetron.github.io/store-microwins/privacy/

## Contents

- `privacy/` — public Privacy Policy HTML
- `screenshots-gp/` — Play Store marketing screenshots
- `screenshots-clean/` — raw clean app screenshots
- `icon-512.png` / `icon-2048.png` — store icons
- `google-play-listing.md` — listing copy
